# Flores, Indonesia Earthquake Project

A seismological data analysis project completed as part of the **Seismology Skill Building Workshop (SSBW) 2026**, organised by EarthScope Consortium.

## Overview

This project explores earthquake analysis and scientific computing using Python, following the workshop's hands-on learning approach.

## Notebook

- `ssbw-project_2026-flores-indonesia-earthquake.ipynb` — Jupyter notebook containing the project workflow, analysis, and visualisations.

## Tools

- Python
- Jupyter Notebook
- Scientific computing and seismological data analysis
